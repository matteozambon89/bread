# Contributing

bread is pre-1.0 (`@breadai/*` packages version independently) and
solo-maintained. The API is still moving, so **the project isn't accepting pull requests yet** —
an unsolicited PR against a package that gets reshaped next week is wasted effort on both sides.

## What's welcome

- **Bug reports** — [open an issue](https://github.com/matteozambon89/bread/issues/new/choose)
  using the bug report template.
- **Feature requests / ideas** — [open an issue](https://github.com/matteozambon89/bread/issues/new/choose)
  using the feature request template. Explain the wall you hit, not just the feature — see
  [Scope discipline](./CLAUDE.md#scope-discipline) for how this repo decides what lands.
- **Questions / discussion** — open an issue; there's no separate discussion board yet.

Once the API stabilizes around 1.0, this file will be updated to cover branching, commit
conventions, and the PR process.

## Reporting a security vulnerability

Do not open a public issue for security reports. See [SECURITY.md](./SECURITY.md).

## Local development

For internal architecture, package layout, and workspace commands (`bun install`,
`bun run typecheck`, `bun run build`, `bun run test`), see [CLAUDE.md](./CLAUDE.md).
